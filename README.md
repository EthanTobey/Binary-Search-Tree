# Binary Search Tree Implementation

## Overview

This repository contains a **Binary Search Tree (BST)** implementation in Java, complete with all standard functionality. The data structure allows for efficient **node insertion**, **deletion**, **search**, and **access**. Additionally, it supports all standard traversal methods, including **in-order**, **post-order**, and **pre-order** traversals.

## Key Features

- **Node Insertion**: Add nodes to the Binary Search Tree while maintaining its properties.
- **Node Deletion**: Remove nodes from the tree, ensuring the structure remains a valid BST.
- **Search and Access**: Efficiently find nodes and access their data using the BST’s search capabilities.
- **Tree Traversals**: Perform in-order, pre-order, and post-order traversals to explore the tree’s structure.

## Technologies Used

- **Java**: The project is implemented in Java, showcasing efficient data structure design and tree operations.
